Split mode

Mathematically you cannot cut an exact 16:9 image into N exact 9:16 tiles that sit side by side and give 16:9 again (N would have to be 3.16). So mode A gives up the tile proportions, B/C give up the aspect ratio of the result.

Resolution

In modes B/C the tile height snaps to the nearest multiple of 32 — the only way to get whole, even 9:16 tile sizes (e.g. 1088×612 instead of 1080).
